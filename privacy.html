개인정보처리방침

시행일: 2026년 11월 18일

「아빠의 왜노트 업로더」(이하 "이 앱")는 채널 「아빠의 왜노트」 운영자가 본인 영상을 관리하려고 만든 개인용 도구입니다.

1. 이용하는 구글 데이터

  • YouTube Data API (youtube.upload): 운영자 본인 채널에 영상을 올리는 데만 씁니다.
  • Google Drive API (drive.file): 이 앱이 만든 파일과 폴더에만 접근해, 검수용 영상과 보고서를 올리는 데만 씁니다.

2. 수집·저장·공유

이 앱은 운영자 외 다른 사람의 개인정보를 수집하지 않습니다. 구글 사용자 데이터를 판매하거나 제3자와 공유하지 않으며, 광고에 쓰지 않습니다. 인증 정보는 운영자의 작업 환경에만 보관됩니다.

3. Google API 서비스 사용자 데이터 정책 준수

이 앱이 Google API에서 받은 정보를 사용하는 방식은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

4. 권한 철회

구글 계정의 서드 파티 연결 페이지에서 언제든 이 앱의 접근 권한을 해제할 수 있습니다.

5. 문의

유튜브 채널 @아빠의왜노트의 정보 페이지를 통해 문의할 수 있습니다.
